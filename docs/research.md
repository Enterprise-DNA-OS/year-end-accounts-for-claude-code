# Selection and source notes

Checked 17 October 2026. New family: accounts-production, year-end accounts and workpapers for accounting practices. The existing accounting-practice family (Karbon, FYI) covers practice workflow and documents; tax-practice covers ATO correspondence. Neither holds a trial balance, journals or sign-off.

| Candidate | Bill basis | Six scores: bill, data, buyers, search, build, import | Total |
|---|---|---|---|
| Caseware | No public price. Caseware Cloud is licensed by active user through sales. | 3, 5, 5, 3, 4, 4 | 24 |
| Silverfin | Vendor's own UK examples: GBP 100 per file a year for 125 files, GBP 60 per file for 2,000 files | 4, 5, 2, 2, 4, 4 | 21 |
| BrightWorkpapers (formerly MyWorkpapers) | Quoted privately | 2, 5, 4, 2, 4, 3 | 20 |

Caseware is used by NZ and AU practices of every size, so buyer fit scores highest, but its price is not published, so the bill score is a judgement, not a sourced figure. Silverfin publishes example prices but sells mostly in the UK and Europe. BrightWorkpapers publishes no prices. No source measured alternative-search volume, so search scores are conservative. No live customer system or invoice was read.

Primary sources:

- [Caseware Cloud licences](https://www.caseware.com/docs/en/cloud/caseware-cloud/explore/licenses-and-mycaseware/before-buying-a-caseware-cloud-license): pricing by number of active users.
- [Caseware Cloud trial balance and adjustments export](https://www.caseware.com/docs/en/cloud/caseware-cloud/engagement-management/accounts-and-analysis/export-adjustments-and-trial-balance-data) and the [Working Papers export guide](https://documentation.caseware.com/2016/WorkingPapers/en/Content/Accounting_and_Assurance/Working_Trial_Balance/t_Exporting_Working_Trial_Balance.htm).
- [Silverfin pricing](https://silverfin.com/en-gb/silverfin-pricing): annual price per client file with worked examples; UK pricing, not a registration in this run.
- [BrightWorkpapers pricing](https://brightworkpapers.au/pricing): quote only.
- Rules: see compliance.md.

No claim is made that Caseware cannot answer these questions, or that the free version replaces every feature. It replaces a bounded year-end workflow for small special purpose files. Demo clients, balances and dates are invented and labelled as demo data.
